# Data Structures & Algorithms (DSA) Solutions

Welcome to the repository for DSA solutions and utility programs.

## 🚀 Projects Included

### 1. Command Line Calculator (`calculator.js`)
A interactive Node.js command-line calculator supporting basic arithmetic operations (`+`, `-`, `*`, `/`).

#### How to Run:
```bash
node calculator.js
```

#### Features:
- Prompts user for input via terminal interface (`readline`)
- Handles division-by-zero validation
- Validates mathematical operators
